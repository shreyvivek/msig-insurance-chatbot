================================================================================
                            ACTUAL DATA FLOW (from run_server.py)
================================================================================

1. USER INPUT → Next.js/React Frontend (page.tsx)
   ↓
2. HTTP POST → FastAPI Server /api/ask (run_server.py:139)
   ↓
3. INTENT CLASSIFICATION → ConversationHandler.handle_question()
   ├─→ Travel question? → TravelBuddy personality
   ├─→ Insurance question? → Policy Intelligence + RAG
   ├─→ Destination mentioned? → ClaimsAnalyzer.analyze_destination_and_recommend()
   └─→ Document upload? → DocumentIntelligence.extract_trip_info()
   ↓
4. CONTEXT ENRICHMENT
   ├─→ User memory (in-memory OR MongoDB if connected)
   ├─→ Claims data (PostgreSQL if connected, via ClaimsAnalyzer)
   ├─→ Policy data (RAG from Policy_Wordings/ + Taxonomy JSON)
   ├─→ User profile (from request or UserProfileManager)
   └─→ Ancileo quotes (if policy request AND ancileo.available_keys)
   ↓
5. LLM ORCHESTRATION → Groq API (REQUIRED)
   ├─→ System prompt (role-based from ConversationHandler)
   ├─→ Business rules & constraints
   └─→ Direct function calls (not MCP tools)
   ↓
6. RESPONSE GENERATION
   ├─→ Personalized answer
   ├─→ Policy recommendations (from PolicyScorer, TaxonomyMatcher)
   └─→ Actionable next steps
   ↓
7. STATE UPDATE
   ├─→ Conversation history (MongoDB if connected, else in-memory)
   └─→ User memory (in-memory + MongoDB if connected)
   ↓
8. HTTP Response → Frontend → User
